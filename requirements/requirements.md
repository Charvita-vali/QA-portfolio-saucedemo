# Requirements

## Business Objective

The objective of the SauceDemo application is to provide users with an e-commerce platform where they can log in, browse products, add items to the shopping cart, and complete the checkout process.

---

## Functional Requirements

FR-001
User should be able to log in using valid credentials.

FR-002
User should not be able to log in using invalid credentials.

FR-003
User should be able to view the product inventory.

FR-004
User should be able to add products to the shopping cart.

FR-005
User should be able to remove products from the shopping cart.

FR-006
User should be able to complete the checkout process.

FR-007
The application should validate mandatory checkout fields.

FR-008
The application should display an order confirmation after a successful checkout.

---

## Assumptions

- The SauceDemo application is available.
- Test users are active.
- Internet connection is stable.
- Google Chrome is used for testing.

---

## Constraints

- Payment gateway is not tested.
- Backend database validation is not performed.
- API testing is out of scope.
